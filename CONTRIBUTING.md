# Contributing to Elevate 2026

Thank you for your interest in contributing to Elevate 2026! We welcome code contributions, documentation improvements, bug reports, and feature proposals.

## Code of Conduct

All contributors and maintainers are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md). Please report any unacceptable behavior to project maintainers.

## How to Contribute

### Reporting Issues

- **Bug Reports**: If you find a bug, please check existing issues to ensure it hasn't been reported yet. If not, open a new issue using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
- **Feature Requests**: If you have an idea for an enhancement, submit a proposal using our [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).
- **Security Vulnerabilities**: Do not report security vulnerabilities in public issues. Please refer to our [Security Policy](SECURITY.md).

### Pull Request Workflow

1. **Fork the Repository**: Create your personal fork on GitHub.
2. **Create a Feature Branch**: Branch off `main` with a descriptive branch name (e.g., `feat/add-worker-pool` or `fix/connection-timeout`).
3. **Develop & Test**: Implement your changes and add corresponding unit and integration tests.
4. **License Headers**: Ensure all newly added source files include the standard Apache 2.0 boilerplate header (see below).
5. **Sign Your Work**: We follow the Developer Certificate of Origin (DCO). Sign off your commits using `git commit -s`.
6. **Submit PR**: Open a pull request against `main` using our [Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md).
