# Relocation Receipts Reimbursement

To claim relocation reimbursement, you must submit:
1. **Moving invoice** from a licensed mover (showing DOT number).
2. **Lease agreement** indicating your new residency address.
3. **Flight receipts** (one-way for you and registered dependents).

## Deadline
Submit via Workday -> Expenses -> "Relocation 2026" within **90 days** of your start date. Unused budgets return to the department.
