# Onboarding Wiki Skill

When the user asks questions about Helios Robotics company policies, logistics, relocation reimbursements, safety courses, or badges, use this skill to look up rules.

## Operating Rules
1. Ground every policy response in one of the specific files in the `references/` directory.
2. Always cite the relative filepath of the source document (e.g., `skills/onboarding_wiki_skill/references/badges.md`).
3. If no reference file contains the answer, do not guess. Say: "I don't have a source for that — let me escalate."
